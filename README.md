# Opstart

Een kleine kickoff over hoe we communiceren en samenwerken. Gemaakt voor Fleur: zeven voorstellen over taal, richting, kanalen, tempo, keuzes, feedback en grenzen. Je kunt ze bijstellen, akkoord geven, en printen. Alles blijft in deze browser bewaard.

## Lokaal starten

```bash
npm install
npm run dev
```

Open [http://localhost:43147](http://localhost:43147).

## Wat je kunt doen

- Namen en openingstekst aanpassen
- Elke afspraak bewerken
- Per punt akkoord geven, of alles in één keer
- Het oorspronkelijke voorstel terugzetten
- Printen als je de afspraken ergens anders wilt neerleggen

Er is geen account en geen database. Wis je browsergegevens, dan is de lokale kopie weg — het voorstel in de code blijft staan.
